# Итоговое задание по курсу "Python для инженерии данных"
Проект реализует DE-задачу репликации данных между разными СУБД-источниками и приемниками с помощью Airflow.

Реализовано с помощью контейнеров docker.
В приемнике создана простая RFM-витрина.

## Запуск на локальной машине
### Подготовка
Для запуска на локальной машине (Ubuntu) клонировать репозиторий,
дать права файлу на запуск:

chmod +x run_first.sh

запустить файл ддя создания необходимых папок для сохранения данных контейнеров 

./run_first.sh
Предполагается, что на локальной машине установлен docker c поддержкой compose версии 2 и выше

### Развертывание Airflow
В папке airflow выполнить

sudo docker compose up airflow-init

sudo docker compose up

### Развертывание Postgres
В папке postgres выполнить

sudo docker compose up

При создании БД происходит ее инициализация сгенерированными данными (скрипт генерации в gen_init_data.ipynb)
### Развертывание MySQL
В папке mysql выполнить

sudo docker compose up

При создании БД происходит создание структуры таблиц-приемников

## Витрина RFM-анализа клиентов
По каждому пользователю находим:

  - число дней с момента последнего заказа (recency)
    
  - общее число сделанных завершенных заказов (frequency)
    
  - общую сумму завершенных заказов (monetary_value)
    
Поля:

user_id - идентификатор клиента

first_name - имя клиента

last_name - фамилия клиента

loyalty_status - статсус клиента в программе лояльности

recency - число дней с момента последнего заказа (10000 - если заказов не было)

frequency - общее число сделанных завершенных заказов

monetary_value - общая сумма завершенных заказов
